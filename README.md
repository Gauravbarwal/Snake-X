# 🐍 Snake Game X

Snake Game X is an advanced Snake game developed using **Python and Pygame**. It extends the classic Snake game with multiple game modes, power-ups, enemies, obstacles, multiplayer gameplay, collision detection, pause functionality, and high-score tracking.

##  Features

-  **Normal Mode** – Classic Snake gameplay with dynamic elements.
-  **Hardcore Mode** – Includes enemies and obstacles for challenging gameplay.
-  **Multiplayer Mode** – Two-player Snake gameplay.
-  **Power-Ups**
    -  Slow Enemies
    -  Shield Protection
    -  Double Score
-  Collision detection
-  High-score tracking
-  Pause and resume functionality
-  Real-time keyboard controls
-  Interactive and user-friendly interface

##  Technologies Used

- **Python**
- **Pygame**
- **Random Module**
- **File Handling**
